# hACK

**Don't hack alone.**

hACK is a web app that helps students find hackathons and connect with other students who are also looking for teammates.

I got the idea because I wanted to participate in hackathons, but I don't have many friends studying computer science who are interested in going. It can be difficult to find people to go with or form a team with, so I wanted to build something that could make that easier.

## Features

- Browse upcoming hackathons
- See information about each hackathon
- Find students who are looking for teammates
- View their skills, interests, major, and experience
- Send an ACK to someone you might want to team up with

## Why ACK?

In computer networks, ACK means acknowledgment. It is used to confirm that something was received.

I used the same idea in hACK. Instead of sending a normal connection request, users can send an ACK to someone they might want to team up with.

## Built With

- Python
- Flask
- SQLite
- Flask-SQLAlchemy
- HTML
- CSS

## What's Next

This is the first version of hACK. I plan to add user accounts, search and filters, better teammate matching, and a way to manage ACK requests.
